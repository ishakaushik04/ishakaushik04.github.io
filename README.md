# Isha Kaushik's Portfolio

Welcome to my portfolio repository! This repo showcases a curated collection of my projects spanning **neuroscience research, human-centered design, and neurotechnology applications**. Each project highlights my approach to problem-solving, research, design, and real-world impact.

## Projects Included
- **Sleep Research (PTSD & REM Sleep):** Investigating neurobiological links and assessment protocols for sleep disturbances in trauma.
- **Columbia DFSI (Amber Waves Apprenticeship Program):** Human-centered design for scaling a social enterprise training program.
- **BehaveNeu NeuroBand:** EEG-based cognitive performance tool validated for attention, emotion, and memory tracking in real-world applications.

Each project has a dedicated folder with its own webpage for detailed insights, images, and results.
